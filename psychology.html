Хичээл 4 · Арилжааны Сэтгэл Зүй

🎯 Арилжааны 90% нь сэтгэл зүй

Техникийн шинжилгээ = 10%. Шийдвэр, сахилга бат, сэтгэл хөдлөл = 90%. Системтэй хүн бүр алддаг, гэхдээ сэтгэл зүйгээ удирдаж чадаагүй хүн бүх ашгаа буцааж өгдөг.

😈 Шунал — Чимээгүй Аллага

  • Ашигтай явж байхад "дахиад бага" гэх — дараа нь буцаж алдах
  • Lot-ыг хэтрүүлэх — нэг алдагдалд бүх ашиг алдах
  • Шийдэл: TP хүрвэл хаана — шунал гарч болохгүй

📋 Арилжааны 8 Алтан Дүрэм

  1. Төлөвлөгөөгөө бичиж, түүнийгээ дага — entry/SL/TP урьдчилан
  2. SL/TP хамт тавихгүй бол бүү ор
  3. Нэг арилжаанд 1-2% л эрсдэл — өвдөхгүй lot
  4. Алдсаны дараа завсарлага — сэтгэл хөдлөлөөр бүү ор
  5. Хөөж бүү ор — setup алдсан бол дараагийнхыг хүлээ
  6. Ашигтай үед хэт их бүү итгэ — дараагийн арилжаа шинэ төлөвлөгөө
  7. Өдрийн алдагдлын хязгаар — тэр өдрийг зогсоо
  8. Алдсан ашгаа бүү тоол — "4111 болчихсон" гэх бодол устга

🔁 Арилжааны Мөчлөг

WIN → итгэл өснө → lot ихэсгэнэ → алдагдал → өшөө арилжаа → дахин алдагдал → айдас → боломж алдах

Энэ мөчлөгийг таслах цэг: амжилтын дараа lot-оо хэвээр барих + алдагдлын дараа завсарлага авах!
