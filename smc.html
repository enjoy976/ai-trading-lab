🎯 SMC Аргачлалын Хичээл

Smart Money Concept — BOS/CHoCH, Order Block, Liquidity Sweep — Алт (XAUUSD) дээрх бодит жишээнүүдтэй

1️⃣ SMC гэж юу вэ?

SMC (Smart Money Concept) = "Ухаант мөнгө" (том банкууд, институцууд)-ын хөдөлгөөнийг chart-аас унших аргачлал.

Гол санаа: Том тоглогчид хямд аваад үнэтэй зарна. Тэд:
  • 🕳️ Liquidity (хүмүүсийн SL) цуглуулахын тулд үнийг хатгадаг
  • 📦 Order Block-д байрлалаа нуудаг
  • 🧩 BOS/CHoCH-оор бүтцээ өөрчилдөг
Бид эдгээрийг илрүүлж, тэдэнтэй хамт арилжаална.

2️⃣ Market Structure (Бүтэц)

Үнийн хөдөлгөөнийг swing high (оргил) ба swing low (ёроол)-оор тэмдэглэдэг:

ТэмдэглэгээУтгаЧиглэл
HH (Higher High)Өндөр дээд📈 BUY
HL (Higher Low)Өндөр нам📈 BUY
LH (Lower High)Нам дээд📉 SELL
LL (Lower Low)Нам нам📉 SELL
Uptrend (BUY): HH + HL = "дээшлээд, бага зэрэг ухраад, дахиад дээш"
Downtrend (SELL): LH + LL = "унаад, бага зэрэг өссөн ч, дахиад унаад"

3️⃣ BOS ба CHoCH (Бүтцийн эвдрэл)

🧱 BOS — Break of Structure (Бүтцийн тасралт)

Трендийн чиглэлд бүтэц тасрах:

  • BOS ▲ (Bullish): Uptrend-д сүүлийн swing high-г дээш тасрах → тренд үргэлжилнэ
  • BOS ▼ (Bearish): Downtrend-д сүүлийн swing low-г доош тасрах → тренд үргэлжилнэ

🔄 CHoCH — Change of Character (Чиглэлийн өөрчлөлт)

Трендийн эсрэг бүтэц тасрах → чиглэл өөрчлөгдөж байна:

  • CHoCH ▲ (Bullish): Downtrend-д сүүлийн swing high-г дээш тасрах → SELL-ээ болих, BUY бэлдэх
  • CHoCH ▼ (Bearish): Uptrend-д сүүлийн swing low-г доош тасрах → BUY-ээ болих, SELL бэлдэх
⚠️ Чухал: BOS = тренд үргэлжлэл, CHoCH = чиглэл өөрчлөлт. Энэ хоёрыг ялгах нь SMC-ийн суурь!
📌 Бодит жишээ (2026-08-06): Алт 4304 дээд үнээс унаад, 4272.7-г тасарлаа = CHoCH ▼ / BOS ▼ → бид SELL рүү шилжсэн. Тэр уналт 4230 хүрсэн.

4️⃣ Liquidity (Хөрвөх чадвар / "Хатгаа")

Liquidity = хүмүүсийн SL, take-profit, limit захиалгууд бөөгнөрсөн газар. Том тоглогчид тэнд үнийг хатгаж (sweep) захиалгуудыг цуглуулдаг.

ТөрөлХаанаЮу болдог
EQH (Equal High)Давхар дээд цэгДээрх SELL SL-ууд → дээш хатгаад буцах
EQL (Equal Low)Давхар нам цэгДоорх BUY SL-ууд → доош хатгаад буцах
💧 Sweep (хатгаа) логик:
  1. Хүмүүс 4250-д BUY орж, SL-ээ 4247-д тавьдаг
  2. Үнэ 4247-г хатгаад SL-уудыг цуглуулна (sweep)
  3. Дараа нь буцаж дээшээ явна (rejection)
  4. Хатгасны дараа үнэ буцах = манай BUY signal! 🎯

5️⃣ Order Block (OB) — Захиалгын бүс

Order Block = хүчтэй хөдөлгөөн эхэлсний өмнөх сүүлийн эсрэг лаа (институцууд тэнд орсон).

  • Demand OB (Bullish): Дээш хүчтэй хөдөлгөөний өмнөх улаан лаа → дэмжлэг
  • Supply OB (Bearish): Доош хүчтэй хөдөлгөөний өмнөх ногоон лаа → эсэргүүцэл
ТөлөвУтгаАшиглах эсэх
Fresh (шинэ)Хүрээгүй, хүчтэй✅ Ашиглана
Mitigated (хүрсэн)Үнэ аль хэдийн OB-г хүрсэн⚠️ Сул
Invalidated (тасарсан)OB эвдэрсэн❌ Битгий
💡 OB дээр хэрхэн арилжаална: Үнэ OB руу буцаж ирэхэд (retest) орно. SL = OB-ийн хязгаараас цааш, TP = дараагийн бүтэц.

6️⃣ FVG — Fair Value Gap (Үнийн зөрүү)

FVG = хүчтэй хөдөлгөөний үед үүссэн "хоосон зай" (3 лааны дунд үүсэх зөрүү). Үнэ ихэвчлэн FVG-ээ бөглөж буцаж ирдэг.

  • Bullish FVG: Дээш хөдөлгөөний үед үүссэн — бөглөхөд дэмжлэг
  • Bearish FVG: Доош хөдөлгөөний үед үүссэн — бөглөхөд эсэргүүцэл
📌 zone индикаторууд (NARROW_ZONE / superindicator) яг эдгээрийг автоматаар зурдаг — OB, HTF zone, FVG, BOS түвшнүүд.

7️⃣ Entry загвар (Sweep + Rejection + Momentum)

🎯 Арилжааны дүрэм (манай аргачлал):

1. Чиглэл: M15+M5 → BOS/CHoCH-оор BUY эсвэл SELL тодорхойл
2. Liquidity: M1 дээр EQH/EQL хай →
3. Sweep: Үнэ liquidity-г хатгана (sweep)
4. Rejection: Хатгасны дараа лаа буцаж хаагдана (rejection close)
5. Momentum: Буцах хөдөлгөөн ATR-ийн 0.4+ байна
6. Entry: Retest/pullback дээр орно (хөөхгүй!)
7. SL: Sweep-ийн хэт цэгээс цааш (бүтцээс)
8. TP: Дараагийн structure / OB / FVG

8️⃣ SL / TP — Бүтцээр тодорхойлох

BUYSELL
SLSweep low / OB-ийн доод хязгаараас 0.5-1.0 доошSweep high / OB-ийн дээд хязгаараас 0.5-1.0 дээш
TP1Дараагийн swing high / resistanceДараагийн swing low / support
TP2Дараагийн OB / том бүтэцДараагийн OB / том бүтэц
⚠️ SL = бүтцээс! Тогтсон "5 оноо" гэх мэт механик SL биш — OB/sweep-ийн хязгаараас гаргана. SL өргөн бол lot-оо багасгана (эрсдэл ижил).

Гурвын аль нэг нь зөрчилдвөл → WAIT!

🔟 Нийтлэг алдаанууд

  1. Чиглэл харалгүй орох — M15 SELL байхад BUY орж байгаа (манай өчигдрийн алдаа 😅)
  2. Хөөж орох — sweep гарсны дараа шууд, retest хүлээхгүй байх
  3. OB тасарсны дараа ч барих — invalidated OB дээр арилжаална
  4. SL-гүй орох — алдагдлын хязгааргүй
  5. TP хэт ойрхон — бага ашиг авч, том хөдөлгөөнийг алгасах
  6. Chop-д олон арилжаа — чиглэлгүй зах зээлд хэт олон орох
  7. Мэдээг шалгахгүй байх — том мэдээний үед хэвийн бус хөдөлгөөн

🔑 SMC-ийн алтан дүрмүүд

  1. Чиглэл → Бүс → Entry гэсэн дарааллаар ажилла (M15 → M5 → M1)
  2. Sweep + rejection баталгаагүй бол бүү ор.
  3. Хөөж бүү ор. Pullback/retest хүлээнэ.
  4. SL = бүтцээс (OB/sweep), тооноос биш.
  5. CHoCH гарсан бол чиглэлээ соль. Зөрүүд бүү бай.
  6. Invalidated OB дээр бүү арилжаал.
  7. Chop-д бүү ороорой. WAIT бол зөв шийдвэр.
  8. Алдсан setup-г бүү харамс. Дараагийнх нь ирнэ.
🎓 Санаж авах хамгийн чухал: SMC бол "том тоглогчдын сэтгэл зүйг" унших урлаг. Хатгаа (sweep) = махчин амьтны занга, OB = тэдний нуугдмал байрлал, BOS/CHoCH = тэдний шийдвэр. Бид тэдэнтэй хамт ажиллана, эсрэг биш!
